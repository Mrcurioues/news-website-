# Glossary

| Term | Definition |
|------|-----------|
| Story | A news article in any state of the editorial workflow |
| StoryStatus | Workflow state: idea → draft → in_review → changes_requested → approved → scheduled → published → archived → trash |
| Breaking | A story with `isBreaking: true` and `status: 'published'` |
| Kicker | Short label above the headline (e.g., "Politics", "Breaking") |
| Byline | Author credit line on the story |
| Homepage Layout | Object mapping layout sections (hero, breaking, secondary, etc.) to arrays of story IDs |
| MediaItem | An uploaded image, video, or document in the media library |
| Activity | An audit log entry on a story recording status changes and notes |
| NDRF | National Disaster Response Force |
| CBDC | Central Bank Digital Currency (Digital Rupee) |
